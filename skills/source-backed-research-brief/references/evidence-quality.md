# Evidence quality and source ledger

Use this reference only when the research question requires source comparison or an auditable evidence trail.

## Source priority

Prefer, in order:

1. Primary material: official documentation, standards, filings, contracts, product pages, original datasets, release notes, or the named publisher's full report.
2. High-quality secondary analysis that links to and accurately characterizes primary material.
3. Search indexes, snippets, reposts, social posts, and unattributed summaries only for discovery; do not use them alone for material claims.

Authority is claim-specific. An official vendor page is authoritative for its own published price, but not necessarily for an independent performance comparison.

## Minimum source record

Give each source a stable ID (`S1`, `S2`, …) and record:

| Field | Requirement |
| --- | --- |
| Title | Exact page, document, dataset, or release title |
| Publisher | Organization or named author |
| Publication date | ISO date when stated; otherwise `not stated` |
| Accessed | Date the source was checked |
| URL | Direct public URL, without tracking parameters |
| Supports | The material claim(s) supported, including scope or unit |
| Limits | Paywall, missing date, vendor interest, sample size, stale data, or other limitation |

If a source cannot be opened, mark it inaccessible and do not imply that its claims were verified. Keep quoted wording short and identify the location (section, page, table, or heading) when useful.

## Conflict protocol

When two sources disagree:

- Normalize units, currency, geography, population, plan tier, and time period before comparing.
- Put the competing values and source IDs side by side.
- Explain a conflict only when the source text supports the explanation; otherwise label it unresolved.
- Prefer the source that is more authoritative for that exact claim and more current, but retain the alternative and state why it was not decisive.
- Propagate the conflict into confidence and recommendation language. A decision can still be conditional, but it cannot be more certain than its material evidence.

## Evidence gaps

Use explicit labels such as `not found`, `not stated`, `inaccessible`, and `not comparable`. Distinguish “the source says no” from “the source does not mention it.” List the smallest follow-up check that would resolve a decision-critical gap.
