# Visual assets

`awesome-workbuddy-banner.webp` is an original repository banner generated with OpenAI's built-in image generation tool on 2026-09-05. It was created specifically for this project, contains no Tencent or third-party logos, and is covered by the repository's CC0 dedication.

The final prompt specified a wide GitHub README banner for an open-source WorkBuddy resource list, an abstract AI companion coordinating documents, spreadsheets, presentations, code, MCP connectors and Skills, exact title and subtitle text, a navy/cyan/teal palette, and no logos, trademarks or watermarks.

The selected image was resized to 1600 pixels wide and encoded as WebP to reduce the checked-in asset from approximately 1.1 MB to 84 KB.
