# Awesome WorkBuddy

[English](README.en.md) · 简体中文

[![Awesome](https://awesome.re/badge.svg)](https://awesome.re) [![Check links](https://github.com/sandbaseai/awesome-workbuddy/actions/workflows/links.yml/badge.svg)](https://github.com/sandbaseai/awesome-workbuddy/actions/workflows/links.yml) [![Latest release](https://img.shields.io/github/v/release/sandbaseai/awesome-workbuddy?label=latest%20release)](https://github.com/sandbaseai/awesome-workbuddy/releases/latest)

腾讯 WorkBuddy 资源导航，帮你找到文档、Skills、MCP 和工作流。

## 立即开始

1. [下载 WorkBuddy](https://www.workbuddy.ai/)，完成官方快速开始。
2. 打开[一分钟上手指南](START_HERE.md)，先完成一个简单任务。
3. 在[资源目录](https://sandbaseai.github.io/awesome-workbuddy/)中按关键词或分类查找工具。

### 常用入口

- [官方文档](https://www.workbuddy.ai/docs/zh/workbuddy/)：功能、安装和常见问题。
- [创建或导入 Skill](https://www.workbuddy.ai/docs/zh/workbuddy/From-Beginner-to-Expert-Guide/Practice-Cases/Create-Skills)：把重复方法变成可复用能力。
- [配置 MCP](https://www.workbuddy.ai/docs/zh/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/MCP-Guide)：连接数据库、消息平台或其他外部工具。
- [创建 Automation](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Automation-Guide)：设置一次性或周期任务。

### 推荐资源

- [WorkBuddyGuide](https://github.com/AlephAITech/WorkBuddyGuide)：中文实战教程。
- [Skill Onboarding](https://github.com/howoneai/skill-onboarding)：快速了解如何制作 Skill。
- [OpenMAIC](https://github.com/THU-MAIC/OpenMAIC)：用多 Agent 制作课程、课件和互动页面。
- [SkillCorpus](https://github.com/EverMind-AI/SkillCorpus)：搜索和加载任务所需的 Skill。

## 按需查找

打开[可搜索资源目录](https://sandbaseai.github.io/awesome-workbuddy/)，按关键词或分类查找：

- 官方文档与使用教程
- Skill 合集和现成 Skill
- MCP、连接器和自动化工作流
- Agent 工具、记忆系统和开发资料
